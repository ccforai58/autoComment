# BacklinkAssistant 1.1.0 使用手册

## 开始前

1. 执行 `npm run local:stack:start`。
2. 打开插件首页，确认服务状态正常。
3. 在“推广网站”中新增或选择一个项目；填写网址和补充介绍，按需获取主页信息。
4. 在“模型配置”完成连通性测试。

## 批量自动提交

1. 进入“工作台”，导入普通 CSV 或 Semrush CSV。
2. 导入成功后会生成待处理列表和草稿；未点击开始也会保留。重复文件会按 URL 去重，不覆盖已有运行/暂停任务。
3. 点击“开始批量处理”。当前任务卡会显示进度、结果分类、当前状态和“今日自动提交 X / 阈值”。
4. 暂停后可在“任务”页继续或删除任务；已完成和暂停任务会保留，除非手动删除。

自动模式只在成功或待确认结果后进入随机间隔。跳过、失败、无评论框和需手动处理会直接进入下一项。间隔启用时，最小值必须大于单页超时时间。

## 自动提交安全限制

在“执行规则 → 自动提交安全限制”中可设置：

- 每日确认阈值：默认 50；达到 50、100、150 等节点时，程序在下一项前询问是否继续。
- 随机间隔：可开关；开启后在最小/最大分钟之间随机选择。

“今日自动提交”只统计当前推广网站当天由批量自动模式产生的成功或待确认记录；半自动、失败和跳过不计入。

## 半自动提交

在目标网页打开手动助手，点击生成并检查自动填入的内容。博客评论会按页面语言生成，并包含与文章和推广网站自然关联的锚文本；提交后由你确认结果。

原生表单提交记录仅在本标签页已主动打开手动助手时写入。批量页面和其他浏览器标签页互不影响。

## 提交记录、检测与资源库

- “提交记录”可查看当前任务和全部本地归档。
- 批量任务运行时外链检测按钮禁用；暂停/完成后可以检测已提交记录。未执行 URL 不进入检测范围。
- “资源库”只积累已验证的外链资源；可按推广项目、提交来源和页面指标筛选、导出。
- 清空当前任务不会删除全部归档；清空推广网站记录会删除该项目对应的本地归档和运行快照。

## 日常操作建议

- 每次只运行一个批量任务，避免任务上下文混淆。
- 暂停后先从“任务”页恢复原任务，再导入新文件。
- 提交前查看 AI 内容和目标表单；不要把“待确认”当作已验证外链。
- 定期在“提交记录”执行外链检测，并在“资源库”维护确认成功的资源。
