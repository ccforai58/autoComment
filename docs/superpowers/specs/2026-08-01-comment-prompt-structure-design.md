# AI 评论提示词三段式增强设计

## 目标

为所有博客评论生成请求追加统一的强制提示词规则。评论需要匹配被评论页面的主要语言，先肯定文章价值，再补充有实质内容的观点，并把推广网站链接作为该观点的自然延伸植入。

## 适用范围

规则在后端的博客评论生成路径统一追加，因此同时覆盖批量评论和半自动助手中的博客评论。目录投稿、个人简介和其他非评论字段不使用该规则。

## 评论结构

1. 第一部分肯定文章价值，并引用文章中的具体主题、观点、方法、实例或读者价值。
2. 第二部分补充一个具体观点、建议或延伸，并在此处自然植入唯一的推广网站 HTML 锚文本。
3. 对英语、法语、阿拉伯语等以空格分词的语言，第一部分约 30 个词、第二部分约 50 个词。
4. 对中文、日文、韩文、泰文、老挝文和缅甸文等不宜稳定按空格计词的语言，第一部分约 50 至 70 个字符、第二部分约 100 至 140 个字符。

## 关联策略

优先使用文章主题、问题、目标读者、方法或工具与推广网站建立直接关联。主题不直接相关时，必须从文章内容中寻找真实的次级关联点，例如写作方法、内容结构、用户体验、页面速度、视觉呈现、工作流、创意灵感、案例表达或受众需求。

评论必须明确说出关联点，不能用“值得学习”或“很有帮助”等空泛表达桥接，也不能捏造文章或推广网站未提供的功能、事实或效果。

## 保持不变

继续保留页面语言识别、避免夸大宣传、唯一 HTML 锚文本、锚文本关键词相关性与去重、以及 href 内真实换行格式要求。

## 验证

为提示词构建逻辑添加测试，断言自定义提示词和默认提示词的博客评论路径均包含三段式、语言长度和关联性要求；非博客的半自动字段生成不追加评论规则。
