# 批量自动提交保护设计

## 目标

为每个推广网站的自动批量提交增加每日分档人工确认、可配置随机间隔和紧凑进度状态，避免半自动助手受影响。

## 规则

- 仅 `batch_auto` 计数，按推广网站和浏览器本地自然日分别累计。
- `success`、`success_pending_moderation`、`submitted_unconfirmed` 都计入；半自动提交不计入。
- 到达设置的确认阈值及其倍数（默认 50）后，在下一次自动提交前要求继续或暂停。确认一次仅放行该档，下一档重新询问。
- 随机间隔可启用或关闭。启用时，每次实际自动处理完成后，随机生成最小至最大分钟之间的一次等待，并持久化该到期时间；关闭时直接继续。
- 间隔最小值必须比单页超时至少多 1 分钟。

## 界面

在现有超时配置下新增自动提交安全限制：确认阈值、启用随机间隔、最小/最大间隔。进度区保留 `进度 X/Y`，在同一位置追加当前阶段；等待时第二行显示倒计时，不增加独立状态卡。批处理窗口最大宽度收紧到约 640px。

## 持久化与恢复

运行快照保存等待到期时间和已确认档位。恢复任务时重新计算本地当天的自动计数；后端无法读取计数时暂停任务。用户拒绝确认后任务进入可恢复的限额暂停状态。

## 测试

纯逻辑覆盖可计数结果、日内按网站计数、阈值、随机等待范围与超时校验；页面测试覆盖设置控件、状态文本和脚本接入。
