# 批量自动提交保护 Implementation Plan

**Goal:** 实现按推广网站每日分档确认、可关闭的随机间隔和紧凑进度状态。

## Tasks

1. 先为 `lib/batch-auto-submit-guard.js` 编写失败测试，定义可计数结果、日内计数、确认档位、随机等待和配置校验。
2. 实现纯逻辑并通过单元测试。
3. 为批处理页面配置控件和状态提示编写失败页面测试，再接入 `chrome.storage.sync` 设置、运行快照和调度前确认。
4. 为后端增加每日自动提交计数接口；当接口不可用时使批处理进入暂停状态。
5. 运行完整测试与扩展页静态检查。
